# Week 05 - Online Bookstore System

## Assignment 2

This assignment extends the online bookstore database with
integrity constraints, deletion policies and relational algebra.

## Files

- constraints.sql: Database integrity constraints.
- violations.sql: Constraint violation tests.
- violations_output.txt: Actual PostgreSQL error output.
- on_delete.md: Foreign key deletion policies.
- seed.sql: Sample database records.
- algebra.md: Relational algebra expressions.
- algebra.sql: Equivalent SQL queries.

## Execution Order

1. sql/schema.sql
