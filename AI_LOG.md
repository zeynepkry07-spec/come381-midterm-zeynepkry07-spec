## Assignment 2

### AI Tool
ChatGPT (OpenAI)

### Purpose
AI was used to develop database constraints, violation tests,
foreign key deletion policies, sample data, relational algebra
expressions and SQL queries.

### Prompts
- Add constraints to the online bookstore database.
- Generate SQL statements that violate these constraints.
- Explain CASCADE and RESTRICT deletion policies.
- Generate sample data and relational algebra queries.
- Provide equivalent PostgreSQL queries.

### Verification
The SQL statements were executed locally using PostgreSQL 16.
Actual constraint violation outputs were saved in
week-05/violations_output.txt.
All eight relational algebra SQL queries executed successfully.

### Reflection
This assignment demonstrates how database constraints protect
data integrity and how relational algebra operations correspond
to SQL queries.

AI-generated code was executed locally to verify its behavior.
